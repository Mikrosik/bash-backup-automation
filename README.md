# Bash Backup Automation

Скрипт для автоматизации резервного копирования серверов с использованием `rsync` и `cron`.

## 🎯 Что делает скрипт:
*   Автоматически создает резервные копии данных по расписанию.
*   Проверяет доступность целевого сервера (или директории) перед началом работы.
*   Ведет логирование процесса (записывает успехи и ошибки в `server-backup.log`).
*   Содержит защиту от ошибок: проверяет наличие переменных окружения перед запуском.

## ⚙️ Как это работает:
1. Скрипт запускается через `cron` (например, каждую ночь).
2. Проверяет, заданы ли переменные `BACKUP_SOURCE` и `BACKUP_DEST`.
3. Запускает `rsync` для синхронизации данных.
4. Если возникают ошибки, пишет их в лог-файл.

## 🚀 Как запустить:
1. Сделайте скрипт исполняемым: `chmod +x backup_auto.sh`
2. Задайте переменные: `export BACKUP_SOURCE="/path/to/source"` и `export BACKUP_DEST="/path/to/dest"`
3. Запустите: `./backup_auto.sh`
